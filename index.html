Autonomiq Boutique Pins: Privacy Policy

Last updated November 5, 2026

Autonomiq Boutique Pins is a private tool that the owner of the Etsy shop Autonomiq Boutique runs on their own computer. It publishes pins for that shop to the shop's own Pinterest business account. It has no other users, and it is not offered to the public.

What the tool accesses

The tool connects only to the shop's own Pinterest account, after the owner signs in on Pinterest's own page. The tool never sees the Pinterest password. It uses this access to:

  • read the account's username, boards and pins
  • create pins, and boards in Pinterest's test area

It does not access, collect or store data about other Pinterest users.

What is stored

  • Sign-in tokens from Pinterest, encrypted, on the owner's computer.
  • A list of pins already posted (file name, pin ID and date), on the owner's computer, so that no pin is posted twice.

How information is shared

Pin content is sent to Pinterest in order to publish it. Pinterest's own privacy policy applies to what Pinterest receives. Pinterest data read by this tool is not sold, is not used for advertising, and is not shared with anyone else.

Keeping and removing data

Sign-in tokens are kept until the owner disconnects the tool. Access can be withdrawn at any time in the Pinterest account's app settings, or by removing the key in the tool. The list of posted pins stays on the owner's computer until the owner deletes it.

Changes

If this policy changes, the new version will be posted on this page with a new date.
